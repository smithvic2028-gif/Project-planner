> [!abstract]
An end-to-end system for scraping programming content, processing it with NLP, organizing knowledge in Markdown, and scheduling learning through planners and calendars.

## 🎯 Project Goals

### Primary Goals
- Automate collection of programming learning content
- Convert raw content into structured Markdown notes
- Apply basic NLP for summaries, keywords, and topics
- Schedule learning sessions using planners and Google Calendar
- Provide a simple, editable user interface

### Constraints
- Local-first
- Python-based
- Markdown-native
- MVP-focused
